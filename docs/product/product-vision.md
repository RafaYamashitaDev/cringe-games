# Cringe Games Product Vision

## What Cringe Games is

Cringe Games is a collection of free, simple, and fast games.

It focuses on familiar, old-fashioned games, the kind that might
affectionately be called "cringe", that remain genuinely enjoyable
to play. The tone is affectionate, not ironic: the games are taken
seriously and built well.

Cringe Games is the product. FreeCell is a game contained in it.

## What every game in the collection offers

- Free: no payment and no account required.
- Fast: quick to open and quick to start playing.
- Simple: easy to understand and use. This describes the experience,
  not the complexity of a game's rules.

These are the only qualities every game in the collection is expected
to share.

## Games

### FreeCell (current scope)

FreeCell is the first game and the only game currently in development
scope. Its rules, experience, platforms, and release requirements are
defined in its own documentation.

### Future games

Additional games are expected. Which games, how many, when, and how
they are built are deliberately undecided. Current work must not be
designed around them. Decisions about a future game will be made when
that game is selected, informed by what FreeCell has taught us.

## Current objective

Release FreeCell as the first Cringe Games game.

## Non-goals

- Selecting or specifying future games.
- Shared game engines, frameworks, plugin systems, or collection-level
  navigation built in anticipation of future games.
- Accounts.
- Multiplayer.
- Monetization.
